# TaskUp - موقع متابعة المهام (واجهة عربية)

أنت معاك حق: المطلوب يكون **موقع فعلي شغال** وليس مجرد صورة.
لذلك المشروع الآن يعمل كسيرفر + واجهة ويب + API محلية.

## ما الذي أصبح “موقع” فعلاً؟
- سيرفر Node محلي (`server.js`) يشغّل الموقع على `http://localhost:4173`.
- API حقيقية بسيطة:
  - `GET /api/health`
  - `GET /api/state`
  - `POST /api/state`
- تخزين البيانات على السيرفر داخل `data/store.json` (وليس فقط داخل المتصفح).
- الواجهة تعرض حالة الاتصال بالسيرفر (Online/Offline badge).

## التشغيل
```bash
npm start
```
ثم افتح:

`http://localhost:4173`

## ملاحظات
- لو السيرفر متوقف، الموقع يشتغل Local Mode على `localStorage`.
- نظام الدفع الحالي Sandbox (تجريبي) داخل الموقع، وليس بوابة دفع حقيقية.
