# تطبيق تحدي الالتزام بالمهام

تطبيق ويب بسيط (واجهة عربية) لتنفيذ فكرتك:
- تسجل المهمة + الوقت.
- ترفع صورة بعد التنفيذ.
- مراجعة "ذكاء اصطناعي" مبسطة تقرر قبول/رفض الإنجاز.
- نظام نقاط: مكافأة عند القبول وخصم عند الرفض.
- متجر نقاط تجريبي للشراء.

## التشغيل

```bash
python3 -m http.server 4173
```

ثم افتح:

`http://localhost:4173`

## ملاحظة مهمة

آلية الذكاء الاصطناعي الحالية **محاكاة محلية** داخل `app.js` وليست نموذج رؤية حقيقي.
يمكن لاحقًا ربطها بـ API رؤية فعلية.
