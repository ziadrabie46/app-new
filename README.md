# TaskUp - منصة التزام المهام (واجهة عربية)

نسخة مطورة من المشروع بشكل أقرب لموقع كامل:

## المزايا
- واجهة متعددة الأقسام: الرئيسية، المهام، الإنجازات، المتجر/الدفع، الحساب.
- إضافة مهمة مع وقت تنفيذ + وصف.
- رفع صورة إثبات لكل مهمة.
- تقييم آلي (AI Simulation) لقبول/رفض الإثبات.
- خصم تلقائي للمهمة المتأخرة بدون إثبات.
- سجل عمليات كامل (إنشاء، قبول/رفض، خصم، دفع، تعديل الحساب).
- نظام شحن نقاط عبر Checkout داخلي يعمل بالكامل محليًا (Sandbox).

## التشغيل
```bash
python3 -m http.server 4173
```
ثم افتح:

`http://localhost:4173`

## حل مشكلة ظهور الصفحة بدون CSS
- تأكد أنك تفتح عبر السيرفر (`http://localhost:4173`) وليس فتح ملف `index.html` مباشرة.
- أضف تحديث قوي للمتصفح (Hard Refresh):
  - Windows/Linux: `Ctrl + Shift + R`
  - macOS: `Cmd + Shift + R`
- تم إضافة cache-busting للملفات (`style.css?v=4` و `app.js?v=4`) لتجنب تحميل نسخة قديمة من الكاش.

## تنبيه
بوابة الدفع هنا **تجريبية محلية** لتجربة تدفق الدفع داخل الموقع.
لو تريد دفع حقيقي (Visa/Mastercard فعلي) نحتاج Backend وربط Stripe/Paymob/HyperPay ومفاتيح API.
